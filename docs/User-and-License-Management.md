# User and License Management

This lab demonstrates practical Microsoft 365 user and license administration in a controlled cloud environment.

The objective is to manage user identities, assign appropriate Microsoft 365 licenses, and verify that users have the services required for their role.

## User Administration

Microsoft 365 user administration includes:

- Creating and managing user accounts
- Reviewing user account information
- Managing user identities
- Assigning licenses and services
- Verifying account configuration

A test user was used in the lab to perform and validate Microsoft 365 administration tasks.

## License Management

Microsoft 365 licenses determine which cloud services and applications are available to a user.

Administration tasks include:

- Reviewing available licenses
- Assigning a license to a user
- Verifying the assigned license
- Confirming that the required services are available

The lab included a Microsoft 365 Business Standard license assigned to the test user.

## Administration Workflow

A typical user and license management workflow is:

```text
Create or identify the user
        ↓
Review account configuration
        ↓
Select the required license
        ↓
Assign the license
        ↓
Verify the assignment
        ↓
Confirm required services
```

## Verification

After making changes, the configuration should be verified through the Microsoft 365 administration tools.

Verification may include:

- Confirming the user's account exists
- Confirming the correct license is assigned
- Confirming Exchange Online is available
- Confirming the user can access the required Microsoft 365 services
